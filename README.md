# 局内卡牌图鉴（In-Run Card Compendium）

《杀戮尖塔 1》的轻量工具 Mod：在**任何局内界面**打开一个和原版看牌界面完全一致的卡牌图鉴。

## 怎么用

- 顶栏地图图标左边多一本书本图标，点开就是图鉴；再点一次 / Esc / 原版「返回」收起。
- 出现时机和原版「牌组」按钮一致：战斗、地图、商店、事件、营火、各类奖励 / 选牌界面都能开，
  收起后回到你点之前那一屏；图鉴开着时顶栏的地图 / 牌组 / 设置可以直接切走。

## 和原版一致的地方

- **手感**：按住任意空白处 1:1 拖动、滚轮按原版步长翻页、右侧原版滚动条（越界回弹），
  5 列 × 0.75 倍卡墙，悬停放大。
- **排序**：稀有度 / 类型 / 耗能 / A-Z，点一下切换升 / 降序，带原版箭头；中文下按原版设置隐藏 A-Z。
- **预览**：点任意卡开原版 `SingleCardViewPopup`，左右箭头能在当前颜色里连续翻阅；
  排序条右侧有原版「看升级版」勾选框。
- **颜色分页**：原版红 / 绿 / 蓝 / 紫 / 无色 / 诅咒用原版名字，模组自定义颜色用枚举名，
  排序条颜色也跟随当前颜色（和原版 `ColorTabBar.getBarColor()` 一致）。

## 和字修的关系

同时装了「字修」时：只要字修设置里的「字典」开着，本模组自动隐藏（避免两个图鉴抢同一个顶栏位置）；
在字修设置里关闭「字典」后，本模组接管（最多 1 秒内生效）。

## 安装

1. 安装 ModTheSpire、BaseMod。
2. 把 `inruncompendium.jar` 放进游戏的 `mods/` 目录。
3. 启动游戏即可，设置入口在 Mods → 局内卡牌图鉴。

适配游戏版本 12-18-2022，Java 8。
